# 车载超低音单元箱体计算分析系统

一款面向车载低音炮箱体设计的**单文件网页工具**：输入扬声器单元的 T/S 参数，实时仿真倒相箱 / 密封箱的低频响应，计算 −3dB 截止频率（F3）、倒相孔尺寸与不同车型的车厢增益，并可一键生成手机友好的计算结果图。

**开发者：乐无间汽车音响 / 邓琰**

![界面截图](screenshot.png)

## 功能特性

- **双箱体仿真**：倒相箱（四阶 Thiele-Small 对齐）与密封箱（二阶 Qtc 对齐）各自独立设定容积，一键切换对比
- **关键指标实时计算**：F3、响应峰值、Fc / Qtc、推荐调谐 Fb
- **三种调谐取向**：音质/平直、均衡/日常、SPL/量感——推荐 Fb 与"单元理论最佳箱体"随取向联动
- **倒相孔计算**：支持矩形槽孔 / 单圆孔 / 双圆孔，输出所需孔长与孔口峰值气流速度评估
- **车厢增益模拟**：两厢轿车、MPV·中大型 SUV、三厢轿车、自由场（尾箱打开展示）四种场景
- **倒相 vs 密封对比表**：两种箱体在各自设定容积下的 F3、电平、滚降、阻尼特性对照
- **一键导出结果图（PNG）**：竖版手机友好排版，含 T/S 参数、关键指标、倒相孔参数、曲线与图例、对比表
- **零依赖单文件**：无需安装、无需联网，浏览器打开即用，电脑与手机均可使用

## 使用方法

1. 下载本仓库的 `index.html`，双击用浏览器打开（或直接把文件拖进浏览器窗口）
2. 在左侧输入单元的 **Fs / Qts / Vas / Xmax**，选择标称尺寸（Sd 自动带出行业典型值，也可选"自定义"手动输入）
3. 设定**单箱净容积、调谐取向、调谐频率 Fb、车型**，右侧实时更新曲线与全部指标
4. 需要圆孔方案时，在"倒相孔形式"中选择并输入孔径，自动给出所需孔长
5. 点击 **「生成结果图片（PNG）」** 保存完整计算报告

> 本仓库已开启 GitHub Pages 的话，可直接访问 `https://<你的用户名>.github.io/<仓库名>/` 在线使用。

## 计算模型

| 项目 | 模型 |
| --- | --- |
| 倒相箱频响 | 四阶 Thiele-Small 无损对齐传递函数 |
| 密封箱频响 | 二阶高通 Qtc 对齐，Qtc = Qts·√(1 + Vas/Vb) |
| 倒相孔长度 | Lv(cm) = 23562.5·Dv²·N / (Fb²·Vb) − 0.732·Dv |
| 车厢增益 | 压力腔经验模型：raw = 10·log10(1 + (fc/f)⁴)，G = cap·(1 − e^(−raw/cap)) 平滑封顶 |

- Sd 为行业典型值，**仅影响倒相孔气流速度估算，不影响频响曲线与 F3**
- 推荐 Fb 判定：音质取向峰值 ≤0.5dB 取下潜最深；均衡取向峰值 ≤3dB 取 35Hz 输出最大；SPL 取向峰值 ≤9dB 取 45Hz 输出最大

## 精度验证

已用 Ground Zero（德国零点）原厂数据交叉验证：

- **GZNW 30SPL-D1**：倒相孔长计算 105mm 与原厂 105mm 完全一致；SPL 取向推荐 Fb ≈ 49.8Hz，与原厂竞赛方案 47Hz 吻合
- **GZHW 30XSPL-D1**：密封推荐容积 29.6L vs 原厂 28L；倒相理论最佳 87L ≈ 原厂 90L；密封 Qtc 0.71 一致
